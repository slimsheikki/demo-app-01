# Claude rules for demo-app-01

## Always confirm before starting work

Before implementing anything — no matter how small — ask the user for explicit confirmation first. Do not begin coding, editing files, or making commits until the user says to go ahead.

## Other standing rules

- Always add a clickable link to the latest deployed version at the end of any response where changes were made: https://slimsheikki.github.io/demo-app-01/standalone.html
- Plan before implementing anything
- Implement one feature at a time
- Railway is parked — GitHub Pages only
- Do not change the width of the layers box (220px)
- Always think twice; push back on technically unsound suggestions
- Only check deploy status when explicitly asked — never proactively
- The Supabase anon key is intentionally public (RLS is the guard); never put the service_role key in client code or the repo
